# 兼容性、覆盖面与发布门槛

## 状态定义

- **编译通过**：代码能生成目标架构文件。
- **隔离测试通过**：合成数据或普通 Qt harness 上的指定行为通过。
- **宿主实测通过**：同一最终产物在具体 Cavalry build、OS、架构和真实窗口上验证。
- **未知 / 不支持**：拒绝自动写入；不能把降级英文的“没有崩溃”记为完整双语。

## 当前版本规则

macOS 写入前匹配 Cavalry 2.7.2 与 Qt 6.6.3。Qt 框架的短版本可能是 `6.6`，以 `CFBundleVersion` 中的完整版本为先；不因此放宽私有 ABI 适配器。
已有自绘 hooks 继续核对映像 UUID / 符号 / 调用链。未知合同回退原始绘制，不猜测内存偏移。
Windows 安装事务与字体枚举尚未完成，不生成带“已验证”标签的 Windows 包。

|---|---|---|
| 工具四个页面的间距、对齐 | 顶部对齐；4/8/16/24 tokens；尺寸分层 | 5 档尺寸的浏览器交互/几何回归 |
| 预览与分段选择圆角 | 结构化示意；12px 轨道 / 4px inset / 8px 内圆角 | 浏览器图像与数值检查 |

| 时间线图层名方框 | QWidget 点文字绘制的字体回退修复路径 | 真实 2.7.2 的可见时间线图层未再出现方框；仍未覆盖所有图层类型和字号 |
| 节点图方框 | 不改写用户图层名，不扩大未验证 Skia ABI hook | 已接入双架构静态合同；依赖关系图拖放后的节点标题/端口仍**未验收** |
| 视口文字漏译 / 颜色 | 固定 Path whitelist、早期配置、双架构 caller 合同；未知 caller 回退英文 | 最新隔离 2.7.2 clone：`ready=1 / recognized=2 / rendered=2 / fallback=0`，可见 `Active Camera`、`Viewport Quality` 与工具提示双语；不是原始 `/Applications` 的新一轮验收 |
| 属性面板只出现中文 / 截断 | 按稳定 nodeType + 字段结构更新 `nodeStrings.json`；AttrControlRow 从合同保护的 +0xb0 完整副本恢复 QLabel 文本、尺寸协商与 tooltip | 最新隔离 clone 中 Duplicator / Editable Shape 切换后 `位置 (Position)`、`旋转 (Rotation)` 完整显示；节点内容与用户场景不改 |
| 字形按钮误译成“胶片” | 修正 Glyphs → 字形 | 字典与格式测试 |
| 所有菜单、对话框、全部功能 | 不自动执行破坏性菜单、不翻译用户内容 | **没有“全覆盖”结论** |

## 跨版本扩展方法

1. 收集目标 OS / Cavalry build / Qt 版本 / 架构 / 模块身份，不借用另一版本结论。
2. 普通 Qt 文本与私有 ABI 自绘分开适配，保持用户输入、模型 ID、文件路径和字体名称原值。
3. 用空白或合成工程记录菜单、弹窗、属性、搜索、时间线、节点图、视口、日志、导出与脚本面板清单。
4. 验证中文、英文、混合文件名 / DPI / 缩放 / 最小窗口 / 常用工作区；检查实际字形、点击命中、数值编辑和保存结果。
5. 测试首次注入、重复更新、升级后拒绝旧备份、权限/签名失败、还原与恢复原版。
6. 有实机证据后才将该组合加入支持矩阵。不要仅扩大版本范围字符串。

## 尚未解除的发布门槛

- 真实 Cavalry 2.7.2 的**修复前**候选已做一轮单次授权验收并逐文件还原；修复后的视口/属性只在隔离 clone 验证。若要把修复后候选加入原始宿主支持矩阵，必须再次得到明确写入授权并完成启动、场景、退出与还原核对。
- 独立 Win 安装/备份/还原实现已加入并有 Rust fixture/check；当前环境缺 MSVC `link.exe`、Windows Qt 6.6.3 SDK、QPA 编译、NSIS、安装器和宿主实机验证；Intel GUI 如提供也需单独构建/验收。
- 精确逐语言字体需求目前只实现回退：若首选英文字体包含汉字，它可能优先承担中文。严格分段仍待实现。
- 历史备份迁移尚未自动化；当前拒绝无校验清单的旧快照。
- 验证最终提交 / 签名产物 / 归档的隐私边界；历史中已存在的个人路径需要单独处理，不能用工作区修复假装历史已清理。
- 凭据的 Contents / Workflows 写能力未以实际写入验证；不会为探测而发布不完整产物。

当前没有发布 v0.1.0 tag / Release，也没有以源码 ZIP 冒充 Win/Mac 安装包。测试前应用本就为 `ours`，回滚恢复到该原状态而非擅自恢复原厂英文。
