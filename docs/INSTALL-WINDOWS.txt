Cavalry Bilingual 0.1.4 — Windows x64
================================================

中文
----
1. 运行 Cavalry-Bilingual_0.1.4_Windows-x64-setup.exe，并按安装器提示完成安装。
2. 需要 Windows x64 和可用的 WebView2 Runtime。安装器未签名，Windows 可能显示 SmartScreen；请只在核对发布页与 SHA256SUMS.txt 后自行决定是否继续。
3. 先保存自己的工程，再自行退出 Cavalry。工具不会自动保存或强制退出宿主。
4. 打开 Cavalry Bilingual，检查排版与字体设置并保存；在状态页刷新检测。若 Cavalry 安装在其他盘或未自动发现，点击“选择路径…”并选择包含 Cavalry.exe 的安装目录。
5. 只有宿主版本、资源和安全合同匹配时才应用。应用后重新打开 Cavalry。
6. 需要回退时选择对应快照。“恢复”是恢复到快照，不一定等于原厂英文状态；恢复前也会保留当前状态。

这是正式发行版本，但当前 Windows 附件仍在 macOS 上交叉构建并进行 NSIS 成员与载荷检查；原生 Windows、MSVC、真实 Cavalry 宿主和完整安装体验尚未验收。不要把 macOS 的 2.8 支持推定为 Windows 2.8 支持。
本包不包含 Cavalry、Qt 或 Skia 的宿主二进制，与 Scene Group / Cavalry 官方无关。
卸载不会自动删除备份或设置，请先检查内容再自行处理。

English
-------
1. Run Cavalry-Bilingual_0.1.4_Windows-x64-setup.exe and follow the installer.
2. Windows x64 and a working WebView2 Runtime are required. The installer is unsigned, so SmartScreen may appear. Proceed only after reviewing the release page and SHA256SUMS.txt yourself.
3. Save your project and quit Cavalry yourself. The tool does not auto-save or force-quit the host.
4. Open Cavalry Bilingual, review and save the typography/font settings, then refresh detection on the Status page. If Cavalry is on another drive or is not detected, choose “选择路径…” and select the folder containing Cavalry.exe.
5. Apply only when the host version, resources, and safety contracts match. Relaunch Cavalry afterwards.
6. To roll back, select a snapshot. Restore returns to that snapshot, not necessarily to a factory English state; the current state is also preserved first.

This is a stable release. The Windows package was cross-built on macOS and checked by NSIS member and payload inspection. Native Windows, MSVC, real Cavalry host, and complete installation acceptance remain incomplete. Do not infer Windows 2.8 support from the macOS 2.8 path.
No Cavalry, Qt, or Skia host binaries are included. This project is not affiliated with Scene Group or Cavalry.
Uninstalling does not automatically remove backups or settings. Review them before deleting anything yourself.
